## Порядок накатки

Собран НА ОСНОВЕ уже применённых `admin-ui-polish.zip` и
`promo-codes-system.zip` (base.html/style.css внутри — кумулятивная

## Что портировано с Platega — и почему НЕ всё

Из 5 KPI на скриншоте Platega:
- **Оборот** и **Средний чек** — перенесены, честно считаются из ваших
  же данных.
- **Прибыль** — НЕ перенесено. У Platega это оборот минус их комиссия
  эквайринга; у вас аналог — оборот минус расходы на сервера/трафик, а
  такие расходы у вас нигде не заносятся. Показать цифру можно было бы
  только выдуманную — не стал.
- **Возврат средств** — НЕ перенесено. В системе нет самого понятия
  возврата/рефанда (ни модели, ни статуса платежа под это).
- **Конверсия** — НЕ перенесено. Требует трекинга «кто открыл экран
  оплаты и не заплатил» — такой телеметрии сейчас не ведётся вообще.

Если действительно нужны все 5 — это отдельная фича (учёт расходов,
модель возвратов, воронка) с новыми таблицами, а не косметика поверх
существующих данных. Скажите, если стоит спроектировать что-то из
этого отдельно.

## Что внутри патча

### 1. Период-фильтр на дашборде (как у Platega: Сегодня/Вчера/7 дней/30 дней/произвольный период)
- `app/admin/routes/dashboard.py` — принимает `?period=` и
  `?date_from=&date_to=` в query, пересчитывает выручку/платежи/средний
  чек/график под выбранный период. Некорректный/пустой ввод тихо
  откатывается на дефолт "7 дней" — не 500-я ошибка.
- Если период длиннее ~2 месяцев — график сам переключается с точек по
  дням на точки по неделям, чтобы не превратиться в нечитаемую кашу.
- Фиксированные карточки "Выручка всего"/"Платежей всего"/"Stars
  всего" никуда не делись — просто теперь они не смешаны с
  период-аналитикой, у каждого блока своя роль.

### 2. Линии/Столбцы — переключатель типа графика
Чистый JS (Chart.js уже используется в проекте) — тип графика меняется
на лету без похода на сервер, те же данные просто рисуются иначе.

### 3. Сворачиваемый сайдбар (иконки-only режим)
Кнопка-стрелка в шапке сайдбара — сворачивает в узкую полосу с одними
иконками, как у Platega. Состояние запоминается в `localStorage`
браузера конкретного админа (у каждого свой, не общая настройка) и
применяется до отрисовки страницы — без "прыжка" при перезагрузке.

## Файлы

- `app/admin/routes/dashboard.py` — логика периода (кроме этого, файл
  идентичен текущей версии на GitHub — включая уже сделанный ранее фикс
  "баланс не в выручке", если вы его ещё не применяли, он тоже здесь).
- `app/admin/templates/dashboard.html` — вёрстка периода + KPI +
  переключатель графика.
- `app/admin/templates/base.html` — кнопка сворачивания сайдбара + JS.
- `app/admin/static/style.css` — все новые стили (`.period-*`,
  `.chart-type-*`, `.sidebar-collapsed`).

## Как накатить

```bash
scp -r app/admin/routes/dashboard.py    user@your-vm:/opt/vpn-bot/app/admin/routes/dashboard.py
scp -r app/admin/templates/dashboard.html user@your-vm:/opt/vpn-bot/app/admin/templates/dashboard.html
scp -r app/admin/templates/base.html    user@your-vm:/opt/vpn-bot/app/admin/templates/base.html
scp -r app/admin/static/style.css       user@your-vm:/opt/vpn-bot/app/admin/static/style.css

sudo systemctl restart vpnapi.service
sudo systemctl status vpnapi.service --no-pager
```

Бот не трогаем — правки только в `app/admin/`, рестарт только `vpnapi.service`.
