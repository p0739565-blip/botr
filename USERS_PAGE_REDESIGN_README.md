# Точная копия дизайна из вашего макета (index.html)

## Важно — это апдейт предыдущего архива users-page-redesign.zip

В этом патче цвета/отступы/шрифты взяты из вашего файла БУКВАЛЬНО, а не
переосмыслены под мою прошлую систему переменных. Раз меняются
переменные в `:root` (`--accent`, `--card`, `--border` и т.д.) — это
затрагивает ВЕСЬ сайт, не только страницу пользователей: все карточки,
кнопки, бейджи, таблицы, сайдбар на всех страницах админки станут
пиксельно того же цвета/радиуса/шрифта, что в вашем макете.

## Единственное место, где я НЕ скопировал буквально — и почему

В сайдбаре вашего макета иконки — не иконочный шрифт, а декоративные
юникод-символы (◌ ♙ ▣ ◔ ◁ ⌁ ◇ ♟ ▱ ♢ ▤). Я оставил как было —
Bootstrap Icons (`bi-people`, `bi-credit-card` и т.д.), а не заменил их
на эти символы. Причина: юникод-символы в отличие от иконочного шрифта
не гарантированно рендерятся одинаково на разных ОС/браузерах (риск
получить "тофу"-квадратики на части устройств админов), и часть из них
не соответствует смыслу пункта (♙ — шахматная пешка — для
"Пользователи"? похоже на плейсхолдер, а не осознанный выбор). Все
остальные визуальные решения — цвета, радиусы, тени, размеры шрифтов,
отступы, стиль кнопок/бейджей/пагинации/карточек — скопированы из
вашего файла один в один, никакой самодеятельности. Если всё же хотите
именно эти символы вместо иконок — скажите, поменяю за минуту, это
однострочная правка в `base.html`.

## Что изменилось относительно прошлого архива

- `:root` в `style.css` — все цвета переопределены на точные значения
  из вашего файла (`--accent: #8b5cf6` вместо `#7c5cff` и т.д.), плюс
  добавлены `--card-hover`, `--danger-soft`, `--ok-soft`,
  `--gray-badge`, которых раньше не было.
- Фон страницы, сайдбар (ширина 248px, `brand-mark` — квадрат с
  градиентом вместо иконки щита), кнопки, бейджи, поля ввода, ячейки
  таблицы, пагинация — все размеры/радиусы/паддинги/тени сведены к
  точным пиксельным значениям из макета.
- Добавлен `.stat-card-plain` — точная копия карточки статистики без
  иконки (104px высота, 14px радиус, 18px паддинг, 27px цифра) —
  применена на странице пользователей вместо более общего `.card-soft`.
- Добавлен `.filter-btn` — точная копия плоских кнопок-фильтров из
  макета (Все/Активные/...), отдельно от круглых `.period-pill` на
  дашборде (те специально сделаны похожими на Platega в прошлом
  патче — разные элементы, разные референсы, не стал их путать).

Функциональная часть (реальный фильтр по статусу, пагинация,
статистика) не менялась — она уже была сделана в прошлом патче,
здесь только визуал доведён до точного соответствия макету.

## Файлы

- `app/admin/static/style.css` — главные изменения здесь.
- `app/admin/templates/base.html` — сайдбар (brand-mark, размеры).
- `app/admin/templates/users.html` — новые классы карточек/фильтров.
- `app/admin/routes/users.py` — не менялся с прошлого патча, включён
  для самодостаточности архива.

## Как накатить

```bash
scp app/admin/static/style.css      user@your-vm:/opt/vpn-bot/app/admin/static/style.css
scp app/admin/templates/base.html   user@your-vm:/opt/vpn-bot/app/admin/templates/base.html
scp app/admin/templates/users.html  user@your-vm:/opt/vpn-bot/app/admin/templates/users.html

sudo systemctl restart vpnapi.service
sudo systemctl status vpnapi.service --no-pager
```

Перезапуск затронет визуал ВСЕХ страниц админки (общие переменные в
`style.css`) — это ожидаемо и есть смысл патча.
