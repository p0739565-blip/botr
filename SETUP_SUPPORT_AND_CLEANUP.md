# Обновление: удаление записей подписок + техподдержка — инструкция

## Что нового

1. **Удаление записей подписок — только супер-админ**
   - На карточке пользователя: чекбоксы у каждой записи подписки + кнопка «Удалить выбранные». Действующую (ещё не истёкшую) подписку удалить нельзя — сначала нужно её отозвать (это защита от случайной потери активного доступа).
   - На странице «Пользователи»: массовая очистка неактивных записей по всей базе, с выбором периода (сутки / неделя / месяц / 3 месяца / 12 месяцев).
   - На карточке пользователя: та же массовая очистка, но только для этого пользователя.
   - На дашборде: последние 3 операции такой очистки (когда, кто, что удалено) — видно только супер-админу.
   - Это жёстко ограничено ролью «Супер-админ» — не делегируется через галочки прав, в отличие от остальных функций панели.

2. **Техподдержка через бота — тикет-система**
   - Новая роль админа: **Техподдержка**.
   - Пользователь в боте: кнопка «🆘 Поддержка» → «📝 Создать заявку» → описывает проблему текстом → прикрепляет фото/видео (не обязательно) → «✅ Отправить заявку».
   - Дальше любые сообщения пользователя автоматически попадают в это же обращение, пока он не нажмёт «❌ Завершить чат с поддержкой» (можно продолжить в любой момент, снова открыв «🆘 Поддержка»).
   - В админке (раздел «Тикеты», доступен супер-админу, обычному админу и техподдержке по умолчанию): список обращений, переписка целиком с вложениями, ответ отправляется пользователю прямо в Telegram.
   - Закрыть обращение → через 1-3 месяца можно массово удалить закрытые (по периоду, аналогично подпискам). Удалить можно только уже закрытое обращение.

## Миграция базы данных

Новые таблицы (`support_tickets`, `support_messages`, `support_attachments`) создадутся автоматически при следующем запуске — `init_models()` вызывается и в боте, и в API при старте, ничего вручную делать не нужно.

**Важно:** если у вас уже были созданы админы через `python -m app.admin.seed` раньше — их логины/пароли/роли сохранятся, ничего пересоздавать не нужно. Новая роль «Техподдержка» доступна сразу при создании/редактировании нового админа через саму панель.

## Перезапуск

```bash
sudo systemctl restart vpnbot.service
sudo systemctl restart vpnapi.service
sudo systemctl status vpnbot.service --no-pager
sudo systemctl status vpnapi.service --no-pager
journalctl -u vpnbot.service -n 30 --no-pager
journalctl -u vpnapi.service -n 30 --no-pager
```

Оба сервиса должны быть `active (running)`, без traceback в логах.

## Важные ограничения — прочитайте внимательно

1. **FSM-состояние диалога с поддержкой хранится в памяти процесса бота** (`MemoryStorage`, стандартно для aiogram без явной настройки). Это значит: если бот перезапустится (обновление кода, падение, `systemctl restart`) **в момент, когда пользователь находится в диалоге с поддержкой**, бот "забудет", что у него открыт диалог. Не страшно: пользователю достаточно снова нажать «🆘 Поддержка» — бот заново найдёт его открытое обращение в базе (оно никуда не делось) и продолжит диалог как обычно. Просто одно сообщение, отправленное ровно в момент рестарта, может не долететь до тикета — попросите написать ещё раз.

2. **Ответ поддержки отправляется как обычное сообщение**, а не полноценный "reply" на исходное — пользователь получит `💬 Ответ поддержки по вашему обращению #N: ...`.

3. **Если пользователь заблокировал бота** — при попытке ответить в тикет админка не упадёт с ошибкой, но покажет предупреждение "не удалось отправить в Telegram", а сам ответ всё равно сохранится в истории обращения.

4. **Вложения (фото/видео) скачиваются на диск сервера** в `app/data/support_media/` в момент получения ботом — не хранятся в Telegram, поэтому не пропадут даже если пользователь удалит переписку у себя. При удалении тикета файлы с диска тоже удаляются.

5. **У пользователя одновременно может быть только одно открытое обращение.** Если он попробует создать новое, пока предыдущее не закрыто, бот просто продолжит существующее.

## Быстрая проверка после разворачивания

1. В боте: «🆘 Поддержка» → «📝 Создать заявку» → напишите тестовое описание → пришлите любое фото → «✅ Отправить заявку».
2. В админке (под супер-админом или техподдержкой): раздел «Тикеты» → должно появиться новое открытое обращение с вашим текстом и фото.
3. Ответьте на тикет из админки — проверьте, что сообщение пришло в бот.
4. Закройте тикет — попробуйте написать что-то в бота ещё раз, должно прийти уведомление "обращение закрыто".
5. На карточке любого пользователя с историей подписок — попробуйте выбрать неактивную запись чекбоксом и удалить (только под супер-админом).
